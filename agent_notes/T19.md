# T19: Storage Chests (`src/logistics/chest.ts`)

Implemented deterministic, headless, fail-closed Wooden (16-slot) and Iron (32-slot) storage chests over `ChestEntity` (`src/types/contracts.ts`), backed by T08 (`src/core/inventory.ts`) and T06 (`src/core/itemRegistry.ts`).

- **Constants & Guards:** `WOODEN_CHEST_SLOTS = 16`, `IRON_CHEST_SLOTS = 32`, `CHEST_CAPACITIES`, `isChestType`, `isChestEntity`, `getChestCapacity`.
- **Factories:** `createChestEntity`, `createWoodenChest`, `createIronChest` (1x1 footprint, `powerNetworkId: null`, `active: false`). Fully compatible with `EntityManager.spawn('wooden_chest' | 'iron_chest', ...)`.
- **Operations:** `canInsertIntoChest`, `insertIntoChest`, `extractFromChest` (specific `ItemId` or first available slot), `extractMatchingFromChest` (whitelist helper for filter inserters), `transferBetweenChests` (strict conservation under partial/full backpressure), slot filter helpers (`setChestSlotFilter`, `getChestSlotFilter`, `clearChestSlotFilter`), and inspection helpers (`getChestItemCount`, `getChestTotalItems`, `getChestUsedSlots`, `getChestFreeSlots`, `isChestEmpty`, `isChestFull`).
- **Invariants:** All item operations validate `ItemId` via `assertValidItemId` (`UnknownItemError`), default to `itemRegistry.getStackSize` (overrideable via `StackSizeResolver`), verify chest inventory slot count integrity, and never lose/duplicate items under full-inventory backpressure.

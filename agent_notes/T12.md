# T12: Belt Network (`src/logistics/beltNetwork.ts`)

Implemented auto-curved corners, sideloading merges, and seamless cross-tile item handoff on top of `T11` (`src/logistics/belt.ts`).

## Key Design Choices
- **Auto-Curved Corners (`computeBeltShape`, `updateBeltShape`, `updateBeltShapesAround`, `updateAllBeltShapes`):**
  - Recognizes `transport_belt` and `underground_belt` (`mode === 'output'`) as adjacent feeders.
  - Back feeder present -> `'straight'`; both left & right feeders (T-junction) -> `'straight'`; only left feeder -> `'curve_left'`; only right feeder -> `'curve_right'`.
- **Sideloading & Handoff Resolution (`resolveBeltHandoff`):**
  - Straight (`srcDir === dstDir`) and matching curved corners (`curve_left` / `curve_right`) preserve the item's lane (`left -> left`, `right -> right`) and enter at `clamp(overflowOffset, 0, 1)`.
  - Perpendicular entry into a `'straight'` belt sideloads both lanes of the feeder onto the target's near lane (`'left'` from target's left, `'right'` from target's right) at `SIDELOAD_ENTRY_OFFSET = 0.5` (+ `overflowOffset`).
  - Head-on opposing belts (`srcDir === oppositeDirection(dstDir)`) resolve to `'blocked'` with strict backpressure and zero item loss.
- **Downstream-First Topological Update (`getBeltUpdateOrder`, `stepBeltNetwork`):**
  - Post-order DFS seeded in ascending `EntityId` order updates downstream belts before upstream belts so handed-off items never double-step in a single tick and full-but-moving chains do not stall.
  - Closed belt loops (cycles) are broken deterministically by ascending `EntityId`.
  - Accepts an optional `externalHandoff(sourceBelt, targetCoord, itemId, lane, overflowOffset) => boolean` callback for non-belt receivers (splitters, underground belts, chests).

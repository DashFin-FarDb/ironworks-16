# T17: Power Grid (`src/logistics/powerGrid.ts`)

Exports `DEFAULT_SUPPLY_RADIUS` (`5`), `DEFAULT_WIRE_REACH` (`7`), `buildPowerGrid`, `rebuildPowerGrid`, `createEmptyPowerGrid`, `canPolesConnect`, `isTileInSupplyRadius`, `isEntityInSupplyRadius`, `getPowerNetwork`, `getEntityPowerNetwork`, `getWireConnections`, `getUncoveredPowerEntities`, and entity predicates (`isPowerPole`, `isPowerProducer`, `isPowerConsumer`, `isPowerAccumulator`, `isPowerParticipant`).

- **Wire Reach:** Two distinct poles connect if squared Euclidean distance `<= min(a.wireReach, b.wireReach)^2` (default `7`). `connectedPoleIds` are stored in ascending `EntityId` order.
- **Supply Coverage:** Square Chebyshev radius (`max(|dx|, |dy|) <= supplyRadius`, default `5`), checking all tiles in an entity's footprint.
- **Partitioning & Determinism:** Connected components of poles are discovered via deterministic BFS ordered by ascending `EntityId`, assigning `PowerNetworkId` starting at `1`. Producers (`steam_engine`, `solar_panel`), consumers (`electric_drill`, `electric_furnace`, `assembler_mk1`, `assembler_mk2`, `research_lab`), and accumulators (`accumulator`) are assigned to the lowest-ID covering network (or `null` if uncovered). Non-electric entities always keep `powerNetworkId = null`.
- **Downstream Notes:** T18 (`powerSolver.ts`) should compute `totalSupplyKw`, `totalDemandKw`, and `satisfaction` on each `PowerNetwork` produced by `rebuildPowerGrid(world)` (initialized with `satisfaction = 1.0`, `totalSupplyKw = 0`, `totalDemandKw = 0`). T41 (`powerOverlay.ts`) can use `getWireConnections`, `isTileInSupplyRadius`, and `getUncoveredPowerEntities`.

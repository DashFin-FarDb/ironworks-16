# T18: Power Satisfaction Solver (`src/logistics/powerSolver.ts`)

Exports `computePowerSatisfaction`, `scaleMachineSpeed`, `solvePowerNetwork`, `solvePowerGrid`, `getEntityPowerSatisfaction`, `getEffectiveMachineSpeed`, `getGlobalPowerSatisfaction`, `SolvePowerOptions`, and `SolvePowerGridOptions`.

- **Satisfaction Formula:** `computePowerSatisfaction(supplyKw, demandKw)` returns `1.0` when `demandKw === 0`, `0.0` when `supplyKw === 0 && demandKw > 0`, and `clamp(supplyKw / demandKw, 0, 1)` otherwise. Fails closed with `SimulationError('INVALID_POWER_VALUE')` on negative, `NaN`, or non-finite values.
- **Accumulator Buffering:** `solvePowerNetwork` sums `currentOutputKw` across producers and `powerDemandKw` across consumers in deterministic ascending `EntityId` order. When `useAccumulators` is true (default) and `dtSeconds > 0` (default `1 / 60`), accumulators proportionally discharge to cover deficits and charge from surpluses while clamping `storedEnergyKj` to `[0, capacityKj]`.
- **Brownout Events:** `solvePowerGrid(world, { eventBus })` solves networks in ascending `network.id` order and emits `powerBrownout` for each network where `demandKw > 0 && satisfaction < 1.0`.
- **Downstream Notes:** Wave 3 electric machines (T23, T25, T26, T27, T30) should use `getEntityPowerSatisfaction(world, entity)` or `getEffectiveMachineSpeed(world, entity, baseSpeed)` (unconnected machines return `0.0`). T50 telemetry can use `getGlobalPowerSatisfaction(world)` for demand-weighted global satisfaction across isolated networks.

# T42: Ghost Placement Preview (`src/render/ghostPreview.ts`)

## Key Design Choices
- **Pure Evaluation + Renderer + Controller:**
  - `evaluateGhostPlacement(world, entityType, position, direction)` evaluates placement validity deterministically per footprint tile using `getEntityFootprint` / `getFootprintTiles` from `src/core/entityManager.ts`.
  - `evaluateGhostAtScreenPos(world, camera, viewport, screenPos, entityType, direction)` converts cursor screen coordinates via `screenToTile` (`T37`) and delegates to `evaluateGhostPlacement`.
  - `renderGhostPreview(ctx, preview, camera, viewport, options?)` renders optional power-pole supply radius (`supplyRadius = 5`), optional translucent sprite via `SpriteAtlas` (`T36`), per-tile green/red tint overlays, outer footprint border, and a directional arrow for directional entities (`transport_belt`, `splitter`, `underground_belt`, `inserter`, `filter_inserter`, `burner_drill`, `electric_drill`).
  - `GhostPreviewController` holds cursor tile, selected `EntityType`, and `Direction` (`rotate()` for `R` hotkey) for clean `T47` (`inputController.ts`) integration.

## Edge Cases & Downstream Notes
- **Placement Blocking Reasons (`GhostPlacementReason`):** Checked per tile in deterministic order: `'out_of_bounds'` -> `'water'` -> `'occupied'` -> `'requires_ore'` (for `burner_drill` and `electric_drill` when `tile.resource === null || tile.resource.amount <= 0`).
- **Multi-Tile Footprints:** `splitter` (2×1) evaluates each tile independently so partially blocked placements render green on valid tiles and red on blocked tiles while marking overall `preview.valid = false`.
- **Viewport Culling:** `renderGhostPreview` returns `false` and emits zero draw calls when both the entity footprint and any power-pole supply radius are outside `getVisibleTileBounds`.
- **Fail-Closed Validation:** Throws `InvalidPlacementError` on unknown `EntityType`, invalid `Direction`, or non-integer tile coordinates.
- **Canvas State Hygiene:** `renderGhostPreview` wraps all drawing in `ctx.save()` / `try ... finally { ctx.restore(); }`.

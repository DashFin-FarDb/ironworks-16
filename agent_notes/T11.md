# T11: Two-Lane Conveyor Belt (`src/logistics/belt.ts`)

Implemented the headless, deterministic two-lane conveyor belt with fixed item spacing and strict backpressure blocking.

## Constants & Exact Arithmetic
- `BELT_SPEED = 0.03125` (`1/32` tile/tick = 1.875 tiles/sec at 60 TPS; exact IEEE-754 power of 2).
- `BELT_ITEM_SPACING = 0.25` (`1/4` tile; exact IEEE-754 power of 2, zero floating-point drift).
- `BELT_MIN_OFFSET = 0`, `BELT_MAX_OFFSET = 1`.

## Key Design Choices for Downstream Tasks (T12–T16, T39)
- **Descending Offset Order:** `lane.items` is maintained in descending `offset` order (`items[0]` is front-most near `1.0`).
- **Zero-Loss Handoff Contract:** `advanceLane` / `advanceBelt` accept an optional `handoff(itemId, lane, overflowOffset) => boolean` callback. Items are only removed from a lane when `handoff` returns `true`; otherwise they halt at `1.0` and trailing items queue at exact `BELT_ITEM_SPACING` intervals.
- **Deterministic Extraction:** `takeItemFromBelt` selects the front-most matching item across both lanes, breaking offset ties by preferring `'left'` before `'right'`.
- **Fail-Closed Validation:** `insertOnLane` validates `itemId` via `assertValidItemId` (throws `UnknownItemError`). Non-finite or out-of-range offsets return `false`; non-positive/NaN `speed` or `spacing` throws `SimulationError`.

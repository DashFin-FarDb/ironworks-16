# T05: Typed Simulation Event Bus (`src/core/eventBus.ts`)

Exports:
- `EventBus` class and `createEventBus()` factory.
- `SIMULATION_EVENT_TYPES`: `['itemProduced', 'entityPlaced', 'entityRemoved', 'researchCompleted', 'powerBrownout']`.
- `Unsubscribe`: `() => void`.

Methods on `EventBus`:
- `on(event, handler): Unsubscribe` — FIFO registration order, idempotent unsubscribe.
- `once(event, handler): Unsubscribe` — auto-unsubscribes before invocation (safe under re-entrant emits).
- `off(event, handler): void` — removes matching handler registrations.
- `emit(event, payload): void` — synchronous, deterministic snapshot dispatch; fails closed (handler errors propagate; invalid event types/handlers throw `SimulationError`).
- `listenerCount(event?): number`
- `clear(event?): void`

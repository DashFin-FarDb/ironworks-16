# Agent Note: T50 - Application Bootstrap & Test Hooks

## Overview
Implemented `src/app/main.ts` and unit tests `tests/T50_main.test.ts`.

## Features
- Application bootstrap wiring Canvas 2D render loop, `Camera`, `InputController`, `SpriteAtlas`, and `ShowcaseHarness`.
- Detection of `?showcase=1` query parameter loading the deterministic `T48` factory on seed `1616`.
- Window test hooks:
  - `window.__STEP_TICKS__(n)` -> advances simulation by `n` ticks.
  - `window.__FACTORY_TELEMETRY__()` -> `{ tick, activeEntities, powerSatisfaction, redScienceProduced, ironPlatesProduced, totalItemsOnBelts }`.
  - `window.__SERIALIZE_STATE__()` -> canonical JSON string of `WorldState`.
  - `window.__INJECT_FAULT__(fault)` -> handles `'blackout'` and `'corrupt_save'`, returning `{ caught: boolean, errorType?: string }`.
- Layered Canvas rendering: background -> terrain & ore patches -> belts & lane items -> entities & inserters -> power overlay -> ghost placement preview -> minimap -> production sparkline -> hotbar & FPS readout -> entity inspector.

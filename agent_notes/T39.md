# T39: Tick-Synced Animated Belts & Moving Lane Items (`src/render/beltLayer.ts`)

## Key Design Choices
- **Tick-Synced Animation (`getBeltAnimationFrame`):** Defaults to `DEFAULT_BELT_TICKS_PER_FRAME = 8`, matching `BELT_ITEM_SPACING / BELT_SPEED = 0.25 / 0.03125 = 8` ticks/frame so the 4-frame belt chevron cycle (`32` ticks) advances in lockstep with `1` tile of item travel.
- **Two-Pass Deterministic Rendering (`renderBeltLayer`):**
  - Entities are viewport-culled via `getVisibleTileBounds`, `isTileVisible`, and `isFootprintVisible` from `T37` (`camera.ts`), then sorted deterministically by `(position.y, position.x, id)`.
  - **Pass 1** draws animated `transport_belt` tiles (`getBeltSpriteKey(shape, direction, frame)`), `splitter` footprints (`entity:splitter`), and `underground_belt` hoods (`entity:underground_belt`).
  - **Pass 2** draws all lane items on visible belts and splitters on top so items near tile boundaries never clip under adjacent belt tiles.
- **Seamless Curved Lane Geometry (`computeBeltItemWorldPosition`):**
  - Straight belts interpolate linearly along `direction` with lateral offset `±BELT_LANE_LATERAL_OFFSET` (`0.22` tiles).
  - Curved belts (`curve_left`, `curve_right`) interpolate along a quarter-circle arc around the inner tile corner so `offset = 0` matches the perpendicular feeder's `offset = 1` and `offset = 1` matches the downstream belt's `offset = 0` with zero seam.

## Edge Cases & Downstream Notes
- **Fail-Closed Validation:** Throws `SimulationError` on negative/non-finite `world.tick`, non-positive `ticksPerFrame`, or non-positive `itemScale`; delegates camera/viewport validation to `camera.ts`.
- **Headless Purity:** Zero DOM globals; uses `SpriteAtlas.draw()` and works cleanly with mock `CanvasRenderingContext2D` in Node/Vitest.
- **Return Telemetry:** `renderBeltLayer` returns `BeltLayerRenderStats` (`{ animationFrame, beltsDrawn, splittersDrawn, undergroundBeltsDrawn, itemsDrawn }`) for diagnostics and downstream integration (`T50`).

# T33: Logistics Recipes (`src/recipes/logisticsRecipes.ts`)

- Exports `LOGISTICS_RECIPE_IDS`, `TRANSPORT_BELT_RECIPE`, `INSERTER_RECIPE`, `POWER_POLE_RECIPE`, `LOGISTICS_RECIPES`, and `registerLogisticsRecipes(registry)`.
- Recipe definitions (all `category: 'assembling'`, `craftingTicks: 30`):
  - `transport_belt`: `1 iron_plate + 1 iron_gear -> 2 transport_belt` (unlocked by default; 2 ingredients, Mk1-compatible).
  - `inserter`: `1 iron_plate + 1 iron_gear + 1 electronic_circuit -> 1 inserter` (`requiredTech: 'automation'`; 3 ingredients, Mk2-compatible).
  - `power_pole`: `2 iron_plate + 2 copper_cable -> 2 power_pole` (`requiredTech: 'solar_energy'`; 2 ingredients, Mk1-compatible).
- Tech gating (`requiredTech`) is aligned 1:1 with `CANONICAL_TECH_DEFINITIONS` in `src/logistics/techTree.ts` (T20).
- All exported arrays and recipe objects are deeply frozen via `Object.freeze`; `registerLogisticsRecipes` uses `registry.registerMany` for atomic, fail-closed registration.

# T43: Build Hotbar & Tick/FPS Readout (`src/ui/hotbar.ts`)

## Key Design Choices
- **Headless-First Architecture:** `Hotbar` and `FpsCounter` are pure TypeScript classes with zero DOM/Window globals and zero `Date.now()` calls. Frame timing is passed explicitly (`frameDeltaMs`), keeping all state deterministic and unit-testable in Node/Vitest.
- **Default 1–9 Build Slots (`DEFAULT_HOTBAR_SLOTS`):** Maps keys `1`–`9` to `transport_belt`, `inserter`, `splitter`, `underground_belt`, `burner_drill`, `stone_furnace`, `assembler_mk1`, `power_pole`, and `wooden_chest` using the `HotbarSlot` contract from `src/types/contracts.ts`.
- **Keyboard & Pointer Integration:**
  - `Hotbar.handleKeyDown(key)` handles `'1'`–`'9'` (select), `'Escape'` / `'0'` (clear selection), and returns `false` for unrelated keys so `T47` (`inputController.ts`) can compose it cleanly.
  - `hitTestHotbar(screenX, screenY, canvasWidth, canvasHeight, slots)` maps canvas clicks directly to slot keys `1`–`9`.
- **Canvas 2D Rendering (`renderHotbar`):** Uses a structural `HotbarCanvasContext` interface compatible with `CanvasRenderingContext2D` to draw the bottom-center 1–9 build toolbar and top-right `Tick: N | FPS: XX.X` readout panel.

## Edge Cases Handled
- **Fail-Closed Validation:** Throws `SimulationError` (`INVALID_HOTBAR_KEY`, `DUPLICATE_HOTBAR_KEY`, `INVALID_FPS_WINDOW`) on invalid constructor/slot configuration.
- **Safe Numeric Handling:** `FpsCounter.recordFrame` ignores `<= 0`, `NaN`, and `Infinity` deltas; `formatTickFpsReadout` clamps negative/non-finite inputs to `0`.

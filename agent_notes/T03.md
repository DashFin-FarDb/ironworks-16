# T03: Fixed-Timestep Tick Loop (`src/core/tickLoop.ts`)

Exports `TickLoop`, `FIXED_TIMESTEP_MS`, `FIXED_TIMESTEP_SEC`, `TickContext`, `PhaseHandler`, `PhaseHandlerMap`, and `TickLoopOptions`:
- Executes `TICK_PHASES` in strict canonical order: `power` -> `mining` -> `smelting_assembling` -> `inserters` -> `belts` -> `stats`.
- `stepTick(world)` increments `world.tick` by 1 and runs all registered phase handlers in FIFO order with `{ world, tick, dt, phase }`.
- `stepTicks(world, count)` runs `count` deterministic ticks; `advance(world, deltaMs)` accumulates scaled time (`ms * ticksPerSecond`, 1000 units = 1 tick) to avoid floating-point drift on whole-ms deltas.
- Fails closed with `SimulationError` on invalid rates, phases, tick counts, delta times, or negative `world.tick`, and propagates handler exceptions without swallowing them.

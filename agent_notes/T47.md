# Agent Note: T47 - Input Controller

## Overview
Implemented `src/app/inputController.ts` and comprehensive unit tests `tests/T47_inputController.test.ts`.

## Features
- Continuous WASD / Arrow camera panning with diagonal normalization ($1/\sqrt{2}$).
- Mouse wheel cursor-anchored zoom via `Camera.zoomAt`.
- `R` (clockwise) and `Shift+R` (counter-clockwise) placement rotation via `GhostPreviewController`.
- Hotbar slot selection (`1-9`), unselect (`Escape` / `0`), with automatic synchronization to ghost placement preview.
- `P` hotkey for toggling `PowerOverlay`.
- Left-click handling: hit-tests hotbar UI first; if tool selected, places entity via fail-closed `evaluateGhostPlacement` and `createEntityInstance`; if no tool selected, inspects entity via `selectEntityAtTile`.
- Right-click handling: deletes entity at cursor tile, clearing full multi-tile footprint and firing `entityRemoved` on `EventBus`.
- Minimal structural interfaces for event targets (`MinimalCanvasElement`, `MinimalKeyboardEvent`, etc.) allowing full headless testing in Node/Vitest with zero DOM mocks required.

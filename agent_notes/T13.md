# T13: 2-Tile-Wide 50/50 Alternating Splitter (`src/logistics/splitter.ts`)

Implemented the headless, deterministic 2-tile-wide 50/50 alternating splitter using `SplitterEntity` from `src/types/contracts.ts` and `advanceLane` / `insertOnLane` / `insertOnBelt` from `src/logistics/belt.ts` (T11).

## Key Design Choices
- **2-Tile-Wide Geometry:** `getSplitterFootprint(direction)` returns `{ width: 2, height: 1 }` for `'N' | 'S'` and `{ width: 1, height: 2 }` for `'E' | 'W'`. `getSplitterTiles`, `getSplitterInputCoords`, and `getSplitterOutputCoords` expose the exact 2-tile occupancy and front/back tile coordinates.
- **50/50 Alternating Routing with Backpressure Conservation:**
  - Each exiting item first attempts `splitter.nextOutputIndex` (`0` or `1`).
  - On acceptance, `nextOutputIndex` toggles to the other output.
  - If the preferred output is blocked, the splitter falls back to the alternate output without losing or duplicating the item, keeping `nextOutputIndex` pointed at the blocked output so it receives priority as soon as it unblocks.
  - If both outputs are blocked, the item halts at `BELT_MAX_OFFSET` (`1.0`) and trailing items queue at exact `BELT_ITEM_SPACING` (`0.25`) intervals.
- **Belt Integration Helper:** `advanceSplitterToBelts(splitter, [out0, out1], options)` directly hands off items into two optional `BeltEntity` outputs while preserving lane side and clamped sub-tile overflow offset.

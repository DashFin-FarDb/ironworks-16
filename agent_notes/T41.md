# T41: Power Overlay (`src/render/powerOverlay.ts`)

Exports `PowerOverlay` (stateful toggle controller), `renderPowerOverlay`, `createPowerOverlayConfig`, `DEFAULT_POWER_OVERLAY_CONFIG`, `computeCoverageSquares`, `computePowerWires`, `computeUnpoweredWarnings`, `computeWarningPulseAlpha`, `getNetworkHealthStatus`, and Canvas2D draw primitives (`drawCoverageSquares`, `drawPowerWires`, `drawUnpoweredWarnings`).

- **Toggleable API:** `PowerOverlay` defaults to `enabled: false` with `toggle()`, `setEnabled(boolean)`, `isEnabled()`, and granular sub-toggles (`showWires`, `showCoverage`, `showUnpoweredWarnings`). When disabled, `render()` is a no-op with zero draw calls.
- **Headless Testability & Determinism:** Uses a minimal `PowerOverlayContext` interface compatible with `CanvasRenderingContext2D` (zero DOM/Window imports). Warning icon pulsing uses a deterministic triangle wave over `world.tick` (48-tick period, alpha `[0.55, 1.0]`).
- **Power Grid Integration & Culling:** Uses `getWireConnections` (T17) for deduplicated pole-to-pole wires with catenary sag, Chebyshev `supplyRadius` clamped to world bounds for coverage squares, and `isPowerConsumer` + `getEntityPowerSatisfaction` (T18) to flag `unconnected`, `blackout`, and `brownout` consumers. All three layers are culled against `getVisibleTileBounds` (T37) and sorted by ascending `EntityId`.
- **Downstream Notes:** T47 (`inputController.ts`) can bind `P` directly to `powerOverlay.toggle()`. T50 (`main.ts`) can call `powerOverlay.render(ctx, world, camera, viewport)` after entity rendering, or call `drawUnpoweredWarnings(ctx, computeUnpoweredWarnings(...))` independently if warnings should remain visible when the overlay is off.

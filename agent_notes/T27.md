# T27: Assembling Machine Mk2 (`src/machines/assemblerMk2.ts`)

- **Specs:** 150 kW (`ASSEMBLER_MK2_POWER_DEMAND_KW`), speed `0.75` (`ASSEMBLER_MK2_CRAFTING_SPEED`), up to 4 ingredients (`ASSEMBLER_MK2_MAX_INGREDIENTS`), 4 input slots, 1 output slot, `1×1` footprint.
- **Exports:** `createAssemblerMk2`, `canAcceptRecipeMk2`, `setAssemblerMk2Recipe`, `insertAssemblerMk2Ingredient`, `extractAssemblerMk2Output`, `tickAssemblerMk2`, `tickAllAssemblersMk2`, plus constants and result/option types.
- **Power & Speed:** Resolves satisfaction via explicit `powerSatisfaction` option or `getEntityPowerSatisfaction(world, assembler)` (T18), defaulting to `0` (fail-closed unpowered halt). Scales progress per tick via `scaleMachineSpeed(0.75, satisfaction)`.
- **Item Conservation & Backpressure:** Verifies output inventory capacity and ingredient availability before advancing; atomically consumes ingredients via `consumeIngredients` (T08) upon completion so recipe changes, blackouts, or full outputs never lose or duplicate items.
- **Fail-Closed & Events:** Rejects smelting recipes, `> 4` ingredient recipes, unknown recipes, locked recipes (when `researchState` or `world.research` is provided), and invalid satisfaction values with typed `SimulationError` / `UnknownRecipeError`. Emits `itemProduced` on `EventBus` (T05) when provided.

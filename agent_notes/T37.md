# T37: Camera & Viewport Culling (`src/render/camera.ts`)

## Key Design Choices
- **Dual API (Pure + Stateful):** Exports both pure functions operating on `CameraState` (`createCameraState`, `panCamera`, `panCameraByPixels`, `centerCameraOn`, `zoomCamera`, `zoomCameraAtPoint`, `worldToScreen`, `tileToScreen`, `screenToWorld`, `screenToTile`, `screenToTileBounded`, `getVisibleTileBounds`, `isTileVisible`, `isFootprintVisible`) and a stateful `Camera` class wrapping them.
- **Coordinate Convention:** `CameraState` (`x`, `y` in world tile units, `zoom` in pixels per tile, default `32`, clamped to `[8, 96]`). Camera `(x, y)` maps to viewport center `(width / 2, height / 2)`. Tile `(tx, ty)` occupies `[tx, tx + 1) × [ty, ty + 1)`.
- **Headless Purity:** Zero DOM/Window/Canvas imports; uses `ViewportSize { width, height }` and `ScreenCoord { x, y }`.

## Edge Cases & Fail-Closed Guarantees
- **Exact-Edge Culling:** `getVisibleTileBounds` uses `Math.floor(topLeft)` and `Math.ceil(bottomRight) - 1` so tiles touching the right/bottom edge at an exact integer boundary are not over-fetched, while partially visible tiles are included.
- **Off-Map Culling:** When the viewport is completely outside `worldBounds`, `getVisibleTileBounds` returns `{ minTileX: 0, maxTileX: -1, minTileY: 0, maxTileY: -1 }` so standard inclusive `for (let x = minTileX; x <= maxTileX; x++)` loops execute zero iterations.
- **Multi-Tile Entities:** `isFootprintVisible(position, footprint, bounds)` performs AABB overlap against `ViewportBounds` for 2×2 / 3×3 machines.
- **Fail-Closed Validation:** Throws `CameraError` (extending `SimulationError`) on non-finite coordinates, `zoom <= 0`, `factor <= 0`, `viewport <= 0`, `minZoom > maxZoom`, negative `paddingTiles`, or non-positive `worldBounds`.

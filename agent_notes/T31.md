# T31: Smelting Recipes (`src/recipes/smeltingRecipes.ts`)

- Exports `SMELTING_RECIPES`, `SMELTING_RECIPE_BY_ID`, `SmeltingRecipeId`, individual frozen recipe constants (`IRON_PLATE_RECIPE`, `COPPER_PLATE_RECIPE`, `STONE_BRICK_RECIPE`, `STEEL_PLATE_RECIPE`), and `registerSmeltingRecipes(registry)`.
- Canonical smelting definitions (60 ticks/sec, all `category: 'smelting'`):
  - `iron_plate`: `1 iron_ore -> 1 iron_plate`, `192` ticks (3.2s)
  - `copper_plate`: `1 copper_ore -> 1 copper_plate`, `192` ticks (3.2s)
  - `stone_brick`: `2 stone -> 1 stone_brick`, `192` ticks (3.2s)
  - `steel_plate`: `5 iron_plate -> 1 steel_plate`, `960` ticks (16.0s), `requiredTech: 'steel_processing'` (aligned with T20 `TechTree`)
- `registerSmeltingRecipes(registry)` uses `registry.registerMany(SMELTING_RECIPES)` for atomic, fail-closed registration.
- Compatible with `RecipeRegistry.findSmeltingRecipeForInput` for T24 (`stoneFurnace`) and T25 (`electricFurnace`) auto-recipe selection.

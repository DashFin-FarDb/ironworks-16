# T02: TileMap (`src/core/tilemap.ts`)

Implemented `TileMap` (default `64×64`, constants `DEFAULT_MAP_WIDTH`, `DEFAULT_MAP_HEIGHT`):
- **Storage:** Row-major flat `Tile[]` array (`index = y * width + x`) accessible via `getTiles()` and reconstructible via `TileMap.fromTiles(width, height, tiles)` for `WorldState` serialization/deserialization.
- **Fail-Closed Bounds:** `inBounds(x, y)` returns boolean; all coordinate reads/writes (`getTile`, `getTileAt`, `getTerrain`, `setTerrain`, `getResource`, `setResource`, `getEntityAt`, `isOccupied`, `setEntityAt`, `occupy`, `getNeighbors`) throw `OutOfBoundsError` on out-of-bounds or non-integer coordinates.
- **O(1) Entity Occupancy:** Direct tile lookup via `getEntityAt(x, y)` / `isOccupied(x, y)`, atomic multi-tile `occupy(x, y, entityId, footprint)`, O(footprint) `clearEntity(entityId)`, `getEntityCoords(entityId)`, and non-throwing `canPlace(x, y, footprint)` (checks bounds, non-water terrain, and unoccupied tiles).

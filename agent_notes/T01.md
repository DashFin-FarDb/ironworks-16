# T01: Shared Contracts (`src/types/contracts.ts`)

Defined the root headless TypeScript contracts covering Waves 1–5:
- **Spatial & Helpers:** `Direction`, `DIRECTIONS`, `DIRECTION_VECTORS`, `TileCoord`, `WorldCoord`, `GridBounds`, `rotateDirection`, `oppositeDirection`, `stepCoord`, `coordKey`, `isWithinBounds`, `clamp`.
- **World & Terrain:** `TerrainType`, `ResourceType`, `ResourceNode`, `Tile`, `WorldState` (row-major `tiles` array, `schemaVersion: 1`), `DayNightState`, `TICK_PHASES`, `TICKS_PER_SECOND = 60`, `DAY_CYCLE_TICKS = 3600`.
- **Items, Recipes & Tech:** `ItemId`, `ItemCategory`, `ItemDefinition`, `ItemStack`, `InventorySlot`, `InventoryState`, `RecipeId`, `RecipeCategory`, `RecipeDefinition`, `TechId`, `TechDefinition`, `ResearchState`.
- **Entities:** Discriminated union `Entity` over all Wave 2 logistics (`transport_belt`, `splitter`, `underground_belt`, `inserter`, `filter_inserter`, `power_pole`, `wooden_chest`, `iron_chest`) and Wave 3 machines (`burner_drill`, `electric_drill`, `stone_furnace`, `electric_furnace`, `assembler_mk1`, `assembler_mk2`, `boiler`, `steam_engine`, `solar_panel`, `accumulator`, `research_lab`).
- **Power, Events & Telemetry:** `PowerNetwork`, `PowerGridState`, `PowerSatisfactionResult`, `SimulationEventMap`, `ProductionStats`, `FactoryTelemetry`, `FaultType`, `FaultInjectionResult`.
- **Fail-Closed Errors:** `SimulationError`, `OutOfBoundsError`, `InvalidPlacementError`, `UnknownItemError`, `UnknownRecipeError`, `DeserializationError`, `InsufficientIngredientsError`.

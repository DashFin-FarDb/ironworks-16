# T25: Electric Furnace (`src/machines/electricFurnace.ts`)

- **Exports:** `ELECTRIC_FURNACE_POWER_DEMAND_KW` (`180`), `ELECTRIC_FURNACE_CRAFTING_SPEED` (`2`), `ELECTRIC_FURNACE_INPUT_SLOTS` (`1`), `ELECTRIC_FURNACE_OUTPUT_SLOTS` (`1`), `ELECTRIC_FURNACE_FOOTPRINT`, `createElectricFurnace`, `insertElectricFurnaceInput`, `extractElectricFurnaceOutput`, `tickElectricFurnace`, `tickAllElectricFurnaces`, `ElectricFurnaceHaltReason`, `ElectricFurnaceTickContext`, and `ElectricFurnaceTickResult`.
- **Power & Speed Scaling:** Queries `getEntityPowerSatisfaction(world, furnace)` and scales `ELECTRIC_FURNACE_CRAFTING_SPEED` (`2.0`, 2× Stone Furnace speed) via `scaleMachineSpeed` from T18. Unconnected furnaces or 0% power satisfaction halt cleanly with `active = false`, `haltReason = 'no_power'`, and zero mutation.
- **Auto-Recipe Selection & Tech Gating:** Automatically selects a smelting recipe from the first available input item using `recipeRegistry.findSmeltingRecipeForInput(itemId)` and verifies `recipeRegistry.isRecipeUnlocked(recipe.id, world.research.completedTechs)`.
- **Item Conservation:** Consumes ingredients atomically via `consumeIngredients` when starting a craft (only if output has space). If `outputInventory` fills mid-craft, `craftingProgress` clamps at `recipe.craftingTicks` with `haltReason = 'output_full'` and delivers outputs cleanly once space frees up—zero item loss.
- **Events & Determinism:** Emits `itemProduced` on `eventBus` (when provided) upon completion. `tickAllElectricFurnaces` iterates `electric_furnace` entities in ascending `EntityId` order.
- **Fail-Closed:** Throws `SimulationError` on negative/NaN `craftingProgress` or `powerDemandKw` or non-smelting `activeRecipe`, and `UnknownRecipeError` if `activeRecipe` is not registered.

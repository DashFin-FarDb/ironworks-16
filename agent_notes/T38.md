# T38: Terrain & Ore-Patch Renderer (`src/render/terrainLayer.ts`)

## Key Design Choices
- **Dual API (Functional + Class):** Exports `renderTerrainLayer(ctx, world, camera, viewport, atlas, options)` and a stateful `TerrainLayer` wrapper class, plus pure helpers `collectVisibleTerrainTiles()` and `computeResourceRichness()`.
- **Viewport Culling:** Uses `getVisibleTileBounds()` and `tileToScreen()` from `T37` (`camera.ts`) to iterate strictly over visible tiles in deterministic row-major order (`y` outer, `x` inner). Off-map viewports exit immediately with `0` tiles rendered.
- **Pixel Snapping (`pixelSnap: true` default):** Computes integer destination rectangles via `dx = Math.floor(rawX)` and `dw = Math.floor(rawX + zoom) - dx` (same for `y`/`h`) so adjacent 16×16 tiles meet with zero subpixel seams at any fractional camera position or zoom.
- **Ore Richness & Depletion:** Active deposits render `resource:<ResourceType>` over the terrain tile. Depleted deposits (`amount <= 0`) are skipped (`depletedSkipped` tracked in stats). Partially depleted deposits smoothly attenuate `globalAlpha` between `0.45` and `1.0` when `showResourceRichness` is enabled (default `true`).
- **Optional Grid Overlay:** `showGrid: true` draws a crisp 1px grid over the visible tile bounds.

## Edge Cases & Fail-Closed Guarantees
- Throws `TerrainRenderError` (subclass of `SimulationError`) if `world.width`/`world.height` are non-positive integers or `world.tiles.length !== width * height`.
- Propagates `CameraError` from `T37` on invalid camera/viewport inputs and `UnknownSpriteError` from `T36` on unrecognized terrain/resource types.
- Accepts `TerrainWorldView = Pick<WorldState, 'width' | 'height' | 'tiles'>` so callers can pass either a full `WorldState` or lightweight fixtures.

# T29: Solar Power & Day/Night Clock (`src/machines/solarPower.ts`)

Exports constants (`SOLAR_PANEL_PEAK_KW = 60`, `ACCUMULATOR_CAPACITY_KJ = 5000`, `ACCUMULATOR_MAX_CHARGE_KW = 300`, `ACCUMULATOR_MAX_DISCHARGE_KW = 300`, `DAY_END_TICK = 1800`, `DUSK_END_TICK = 2160`, `NIGHT_END_TICK = 3240`), clock helpers (`normalizeCycleTick`, `getDayNightPhase`, `computeSolarFactor`, `createDayNightState`, `advanceDayNightClock`), solar panel updaters (`updateSolarPanel`, `updateAllSolarPanels`), accumulator helpers (`getAccumulatorChargeRatio`, `chargeAccumulator`, `dischargeAccumulator`, `balanceNetworkAccumulators`), and the world tick entry point `tickSolarPower(world, options?)`.

- **3,600-Tick Piecewise-Linear Schedule:** `[0, 1800)` Day (`solarFactor = 1.0`), `[1800, 2160)` Dusk (linear `1.0 -> 0.0`), `[2160, 3240)` Night (`solarFactor = 0.0`), `[3240, 3600)` Dawn (linear `0.0 -> 1.0`). Cycle-average `solarFactor` is `0.6` (`36 kW` average per `60 kW` panel).
- **Power Phase Integration:** `tickSolarPower(world)` advances `world.dayNight` and updates every `solar_panel` entity's `currentOutputKw` and `active` flag in ascending `EntityId` order. It intentionally does not double-charge/discharge accumulators so it composes directly before `solvePowerGrid(world)` (T18) in the `'power'` tick phase.
- **Fail-Closed Validation:** Throws `SimulationError('INVALID_CYCLE_TICK')` on non-integer or negative `deltaTicks` and `SimulationError('INVALID_SOLAR_VALUE')` on negative, `NaN`, or non-finite power/energy inputs.

# T07: Recipe Registry (`src/core/recipeRegistry.ts`)

- Exports `RecipeRegistry`, `createRecipeRegistry`, `CANONICAL_ITEM_IDS`, and `ItemValidator`.
- `new RecipeRegistry(itemValidator?, initialRecipes?)` accepts a T06 `ItemRegistry` (`{ hasItem }`, `{ has }`, `ReadonlySet<string>`, or `(id: string) => boolean`), defaulting to `CANONICAL_ITEM_IDS` from `contracts.ts`.
- Fails closed: throws `UnknownItemError` for any unknown ingredient/output `ItemId`, `UnknownRecipeError` on missing `get()`/`isRecipeUnlocked()`, and `SimulationError` on duplicate IDs or invalid counts/durations.
- Provides `register`, atomic `registerMany`, `get`, `has`, `listAll`, `getByCategory`, `getByOutput`, `findSmeltingRecipeForInput` (for T24/T25 furnaces), `isRecipeUnlocked`, and `getUnlockedRecipes`.

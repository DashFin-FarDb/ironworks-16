# T36: Procedural 16×16 Sprite Atlas (`src/render/spriteAtlas.ts`)

## Design Choices
- **Pure RGBA Pixel Buffers + Lazy Canvas Caching:** Every sprite is generated deterministically into a `16×16` RGBA `Uint8ClampedArray` (`1024` bytes) using ASCII-art pixel patterns and exact 90° clockwise buffer rotations (`rotateBufferCW`). When running in a browser (`document.createElement` available), `atlas.getCanvas(key)` lazily caches a `16×16` `HTMLCanvasElement` for fast `ctx.drawImage()` with `imageSmoothingEnabled = false`. In headless Node/Vitest environments, `atlas.draw(ctx, key, dx, dy, dw, dh)` falls back to `ctx.fillRect()` per non-transparent pixel.
- **Complete Coverage:**
  - **Terrain (`terrain:<TerrainType>`):** All 5 terrain types (`grass`, `dirt`, `sand`, `water`, `stone_ground`), fully opaque.
  - **Resources (`resource:<ResourceType>`):** All 4 ore types (`iron_ore`, `copper_ore`, `coal`, `stone`) with transparent backgrounds for terrain overlay.
  - **Items (`item:<ItemId>`):** All 21 `ItemId`s with distinct silhouettes and transparent backgrounds.
  - **4-Frame Animated Belts (`belt:<BeltShape>:<Direction>:<0..3>`):** All 48 variants (`straight`, `curve_left`, `curve_right` × `N/E/S/W` × 4 frames). `getBeltSpriteKey()` normalizes any integer frame (including negative) modulo `BELT_FRAME_COUNT` (`4`).
  - **Entities (`entity:<EntityType>` and `entity:<EntityType>:active`):** All 19 `EntityType`s, with distinct active/glowing sprites for `burner_drill`, `electric_drill`, `stone_furnace`, `electric_furnace`, `assembler_mk1`, `assembler_mk2`, `boiler`, `steam_engine`, and `research_lab` (and active aliases for `solar_panel` and `accumulator`).
  - **Inserter Parts (`inserter:basic|filter:base|arm`):** Separate base and arm sprites so `T40` (`entityLayer.ts`) can rotate the arm around the base using `entity.armAngle`.

## Edge Cases & Downstream Notes
- **Fail-Closed Lookups:** `atlas.getSprite(key)` throws `UnknownSpriteError` (subclass of `SimulationError`) if a key does not exist. Use `atlas.hasSprite(key)` before querying optional `:active` variants for passive logistics entities (e.g., chests, poles, belts).
- **Strict Determinism:** Zero `Math.random()` or `Date.now()` calls. `hashSpritePixels()` provides an FNV-1a 32-bit checksum for verification.

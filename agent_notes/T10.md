Exports:
- `canonicalStringify(value: unknown, path?: string): string` — Deterministic JSON serializer with lexicographically sorted keys, `-0` -> `0` normalization, and fail-closed `SimulationError('SERIALIZATION_ERROR', ...)` on non-finite numbers (`NaN`, `Infinity`).
- `serializeWorldState(state: WorldState): string` — Canonical JSON serialization of `WorldState`.
- `deserializeWorldState(json: string): WorldState` — Fail-closed deserialization and structural/invariant validation of `WorldState`; throws `DeserializationError` on malformed JSON, unsupported `schemaVersion`, invalid tile dimensions/coordinates, invalid entity/terrain/resource/item/tech enums, or out-of-range numbers.
- `hashWorldState(state: WorldState): string` — Deterministic 32-bit FNV-1a hex digest of the canonical serialized `WorldState`.

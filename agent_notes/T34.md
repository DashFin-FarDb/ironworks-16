# T34: Science Recipes (`src/recipes/scienceRecipes.ts`)

- Exports deeply frozen `RED_SCIENCE_RECIPE`, `GREEN_SCIENCE_RECIPE`, `SCIENCE_RECIPES`, and `registerScienceRecipes(registry: RecipeRegistry)`.
- `red_science`: `1 copper_plate + 1 iron_gear -> 1 red_science`, `category: 'assembling'`, `craftingTicks: 300` (5s base; 600 ticks in Assembler Mk1 at speed 0.5), unlocked from start (`requiredTech` omitted).
- `green_science`: `1 inserter + 1 transport_belt -> 1 green_science`, `category: 'assembling'`, `craftingTicks: 360` (6s base), gated by `requiredTech: 'logistics'` (aligned with `T20` tech tree).
- Both recipes have 2 ingredients, making them craftable in both Assembler Mk1 (`<= 2` ingredients) and Assembler Mk2 (`<= 4` ingredients).
- `registerScienceRecipes` uses `registry.registerMany(SCIENCE_RECIPES)` for atomic, fail-closed registration and validation against `T06`/`T07`.

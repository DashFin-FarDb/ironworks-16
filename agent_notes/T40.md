# T40: Entity Layer Renderer (`src/render/entityLayer.ts`)

## Key Design Choices
- **Two-Pass Deterministic Render Order:** Visible entities are culled via `getVisibleTileBounds` + `isFootprintVisible` (from `T37`) and sorted by `(position.y, position.x, id)`. Pass 1 renders machines and passive structures (`wooden_chest`, `iron_chest`, `power_pole`, etc.); Pass 2 renders `inserter` and `filter_inserter` on top so rotating arms reach cleanly over adjacent machines/chests.
- **Active/Idle Machine Sprites & Indicators:** `resolveEntitySpriteKey()` selects `entity:<type>:active` when `entity.active` is true and the atlas has it, falling back to `entity:<type>`. All 11 machine types render a top-right LED status dot (`#3ddc84` active, `#f0ad4e` idle, with `#1a1a1a` border).
- **Deterministic Furnace Glow:** Active `stone_furnace` and `electric_furnace` entities render a concentric warm glow overlay whose alpha pulses deterministically via `computeFurnaceGlowAlpha(world.tick, entity.id)` in `[0.2, 0.5]` (zero `Date.now()` / `Math.random()`).
- **Rotating Inserter Arms & Held Items:** Draws `inserter:basic|filter:base`, then translates to tile center and rotates `inserter:basic|filter:arm` by `entity.armAngle + Math.PI / 2` (aligning the North-pointing arm sprite from `T36` with `T15`'s `E=0, S=π/2, W=π, N=-π/2` convention). When `entity.heldItem !== null`, draws `item:<ItemId>` at the arm's claw tip.

## Edge Cases & Downstream Notes
- **Belt Skipping:** `transport_belt` is skipped by default (`skipTransportBelts: true`, handled by `T39` `beltLayer.ts`). Pass `skipAllBeltLogistics: true` if `T39` also renders `splitter` and `underground_belt`.
- **Fail-Closed Validation:** Throws `EntityLayerError` (extending `SimulationError`) if `world.tick` or any visible inserter's `armAngle` is non-finite.
- **Dual API:** Exports both functional `renderEntityLayer(...)` and stateful `EntityLayer` class wrapper for `T50` (`main.ts`).

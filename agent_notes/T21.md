# T21: ResourceNode (`src/machines/resourceNode.ts`)

Implemented finite ore deposit helpers operating directly on `ResourceNode`, `Tile`, and `TileMap` (plain serializable data, zero class-prototype drift).

## Exports
- `RESOURCE_TYPES`, `isValidResourceType(value)`, `assertValidResourceNode(node)`
- `createResourceNode(type, amount): ResourceNode` — requires valid `ResourceType` and positive integer `amount`; sets `initialAmount = amount`.
- `isDepleted(node)`, `getRemainingAmount(node)`, `getRemainingRatio(node)` — null-safe, never return `NaN`.
- `mineOne(node): MineResult` — decrements `node.amount` by 1 when `> 0`, halts cleanly at `0` (`{ mined: false, itemId: null, remaining: 0, depleted: true }`), never goes negative.
- `mineOneFromTile(tile): MineResult` & `mineOneAt(tileMap, coord): MineResult` — mines 1 unit and cleans up `tile.resource = null` immediately upon depletion.
- `mineOneFromFootprint(tileMap, origin, footprint): MineResult` — deterministic row-major (`dy`, then `dx`) scan for drills (T22/T23); validates all footprint bounds before mutating.

## Notes for Downstream Agents (T22, T23, T38, T44)
- `ResourceType` (`'iron_ore' | 'copper_ore' | 'coal' | 'stone'`) is directly assignable to `ItemId`.
- Use `mineOneFromTile` / `mineOneAt` / `mineOneFromFootprint` so depleted deposits are automatically cleared (`tile.resource = null`).

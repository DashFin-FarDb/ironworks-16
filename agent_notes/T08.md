# T08: Slot-Based Inventory (`src/core/inventory.ts`)

Implemented deterministic, headless, fail-closed slot-based inventory over `InventoryState` from `src/types/contracts.ts`:

- **Standalone pure/state functions:** `createInventoryState`, `cloneInventoryState`, `setSlotFilter`, `getSlotFilter`, `clearSlotFilter`, `getItemCount`, `getTotalItemCount`, `isEmpty`, `isFull`, `canInsert`, `insertItem`, `removeItem`, `hasItems`, `consumeIngredients`, `consumeIngredientsOrThrow`, `getFirstAvailableItem`.
- **Class wrapper:** `Inventory` wrapping `InventoryState` and an optional `StackSizeResolver`.
- **Stack size integration:** Accepts an optional `StackSizeResolver = (itemId: ItemId) => number` (defaults to `DEFAULT_STACK_SIZE = 50`) so downstream Wave 2/3 modules can pass `itemRegistry.getStackSize` directly without circular/build-order coupling.
- **Insertion priority:** (1) existing partial stacks -> (2) empty slots filtered to `itemId` -> (3) empty unfiltered slots, all in ascending slot order.
- **Atomic consumption:** `consumeIngredients` aggregates duplicate `ItemId` entries, pre-verifies all counts, and either removes all or mutates nothing.
